# Code of Conduct

## Our standard
Be respectful. Assume good intent. Focus critique on ideas and code, not people.

## Unacceptable
Harassment, doxxing, posting exploit details that endanger production users without coordinated disclosure, and spam.

## Enforcement
Maintainers may moderate issues, PRs, and discussions. Report concerns via the contacts in [SECURITY.md](SECURITY.md).

## Attribution
Adapted for a small open-development relay project; spirit aligned with the Contributor Covenant.
