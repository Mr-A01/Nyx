# NYX Engineering Team Roles & Protocols

## Roles
- **Lead**: Architecture oversight, integration, release synchronization, quality gatekeeping.
- **Backend**: PHP modular implementation, API controllers, services.
- **Security**: Authentication, rate limiting, vulnerability audits, E2EE verification.
- **Frontend**: Web client assets, UI/UX components in `public/`.
- **QA/Test**: Automated test execution, regression suites, syntax checks.
- **DevOps/Infra**: Docker setup, compose configuration, deployment scripts.

## File Ownership & Collaboration
Coordinate changes to shared files to avoid merge conflicts. Use feature branches and Pull Requests for all non-trivial changes.
