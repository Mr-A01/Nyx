FEDERATED • END-TO-END ENCRYPTED

Private conversations beyond the central cloud

A federated messenger built around end-to-end encryption, independent relay nodes, and the freedom to run your own network.

WHY NYX

A network of relays.
Not a single cloud.

NYX is built around small relay nodes that can run on ordinary shared hosting. Clients use a stable Protocol 3 API, while private message content is encrypted on-device. Relays move data across the network; they are not the source of truth for your conversations.

THE NETWORK

Private by design.
Distributed by nature.

End-to-End Encryption

Message payloads are encrypted on the client with libsodium before they pass through a relay.

Federated Relay Mesh

Independent nodes connect through peer discovery, gossip, topology and membership updates.

Run Your Own Node

Deploy on PHP-capable shared hosting or run a node with Docker. Your infrastructure, your rules.

Activity-Based Credits

NYX credits follow useful relay activity—not idle proof-of-work or wasted CPU cycles.
