Federated E2EE messenger for real relays

NYX runs as a modular PHP relay mesh — shared hosting or Docker — with client-side encryption, activity-metered incentives, and an operator-friendly work-chain. Servers move ciphertext; they are not the vault of private meaning.

View repository Install guide Docker

Privacy by design

End-to-end encryption on the client (libsodium). Relays prefer ciphertext; identity and devices stay under user control.

Federation mesh

Multi-domain topology, gossip, peer authentication options, and live network health endpoints for operators.

Activity-metered mining

Rewards track useful work — message relay, probes, storage — not idle hashing on shared hosts.

Ship anywhere

public/ document root for shared hosting, or ghcr.io/mr-a01/nyx for containers.

Architecture

Hexagonal modules under app/, JSON FileStore as source of truth, optional SQLite index, PWA shell in public/.

Operator cheatsheet

  • GET /api/v3/ops/selftest — health
  • GET /api/v3/ops/network — mesh snapshot
  • POST /api/v3/ops/gc — maintenance GC (Bearer)
  • GET /api/v3/mining/status — rates + activity meter
